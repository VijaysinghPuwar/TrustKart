# Product image audit

Audited 2026-09-28: all 113 catalog product images, plus 11 category tiles.

Two passes:

1. **Deterministic checks** (`python3 scripts/validate_images.py`, also run in CI): every image exists, is non-empty, is a valid
   WebP, meets the minimum resolution, has recorded dimensions that match the file, has alt text and recorded provenance,
   and no file is reused across unrelated products. **Result: 0 errors.** No broken or missing images.
2. **Manual premium review** of every image against the TrustKart product-media standard (brand-new looking, correct
   model or visually identical product line, plain light or studio background, no people/hands, no desk/store/room/expo
   setting, no clutter, packaging or damage).

## Summary

| | Count |
|---|---|
| Images audited | 113 products + 11 category tiles |
| Broken / missing / zero-byte / wrong format | 0 |
| Exact model | 17 |
| Pass premium review | **26** |
| Fail premium review | **87** |
| Category tiles passing | 0 (all are room/desk photographs) |

Why so many fail: every image came from Wikimedia Commons, where freely licensed photos of current retail hardware are
mostly amateur shots (stores, desks, trade shows) or older models. Commons rarely has clean studio photography of new
products, so a Commons-only pipeline cannot reach the premium standard for most of this catalog.

Main failure reasons: store/expo photographs (13), desk/room/table settings (19), wrong or much older model (31),
different brand shown as the product (17), packaging/clutter/used appearance (7).
